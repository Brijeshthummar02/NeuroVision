# ⚙️ Project Setup

Follow these steps to set up the project locally. 🖥️

## 1️⃣ Fork the Repository

Click the **Fork** button on the top-right corner of this repository.

---

## 2️⃣ Clone Your Fork

```bash
git clone https://github.com/your-username/repository-name.git
````

---

## 3️⃣ Navigate to Project Folder

```bash
cd repository-name
```

---

## 4️⃣ Install Dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

## 5️⃣ Start Development Server

```bash
npm run dev
```

or

```bash
npm start
```

# 🌿 Branch Naming Convention

Please create a separate branch for your work.

## 📌 Branch Format

```bash
feature/feature-name
bugfix/bug-name
docs/documentation-update
```

## ✅ Examples

```bash
feature/login-page
bugfix/navbar-error
docs/update-readme
```

# 🧹 Coding Guidelines

Please follow these coding standards to maintain clean and readable code. ✨

## ✅ General Guidelines

* Write clean and maintainable code
* Use meaningful variable and function names
* Keep functions small and modular
* Add comments where necessary
* Avoid unnecessary dependencies
* Follow existing project structure
* Remove unused code before committing

---

## 🎨 Frontend Guidelines

* Maintain responsive design 📱
* Use reusable components ♻️
* Keep UI consistent 🎯
* Follow accessibility practices ♿

---

## ⚡ Backend Guidelines

* Validate inputs properly
* Handle errors gracefully
* Keep APIs optimized
* Use proper status codes

# 📝 Commit Message Guidelines

Write clear and meaningful commit messages.

## ✅ Recommended Format

```bash
type: short description
```

## 📌 Examples

```bash
feat: add dark mode
fix: resolve login issue
docs: update contributing guide
style: improve button alignment
refactor: optimize API calls
```

# 🔄 Pull Request Process

Please follow these steps before submitting a Pull Request. 🚀

## ✅ Before Submitting

* Ensure the project builds successfully
* Test your changes properly
* Check for formatting issues
* Make sure there are no console errors
* Update documentation if needed

---

## 📌 Steps to Create PR

1️⃣ Fork the repository
2️⃣ Clone your fork
3️⃣ Create a new branch
4️⃣ Make your changes
5️⃣ Commit changes
6️⃣ Push to GitHub
7️⃣ Open Pull Request

---

## 🧾 PR Title Format

```bash
type: short description
```

### ✅ Examples
